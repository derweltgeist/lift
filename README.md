# Lift Simulator

Part of ITB's WI 1102 "Computational Thinking" mid-term project.

## Description

A collection of modules aimed to simulate an elevator, linked via streamlit framework.
Here are the list of modules:
- User Interface: Including the buttons and how does it interact with the users.
- Main mechanism: Including how the lift, the counterweight, the motor, and the cable.
- Emergency Mechanism: Including brakes for the cable, the weight limit, etc.
- Stress Test: Insert various parameters (e.g. people jumping, etc) to see whether the cable will snap or not.
